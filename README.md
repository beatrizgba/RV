# Computação Gráfica e RA/RV

## Rasterização de Quadriláteros e Transformações Geométricas 2D
Projeto desenvolvido para a disciplina de Computação Gráfica e RA/RV, com o objetivo de implementar algoritmos básicos de rasterização, preenchimento de polígonos e transformações geométricas bidimensionais utilizando Python.

O programa permite criar um quadrilátero a partir de quatro pontos informados pelo usuário, preencher sua região interna e aplicar transformações de escala e rotação em relação à origem da tela ou ao centroide da figura.

As operações gráficas são implementadas diretamente sobre os pixels da imagem, sem utilizar funções prontas para desenhar ou preencher polígonos.
